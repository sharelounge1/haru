# 하루비서 모바일 앱 화면 기획서

## 1. 앱 개요

### 앱 타입
- **네이티브 스타일 웹앱** (모바일 최적화)
- **타겟**: iOS/Android 모바일 디바이스
- **UI/UX**: 하단 네비게이션 바, 터치 최적화, 네이티브 앱 느낌

### 주요 사용자 그룹
1. **경영자 (Client)** - 비서를 찾는 사용자
2. **비서 (Secretary)** - 일자리를 찾는 전문 비서
3. **관리자 (Admin)** - 플랫폼 운영자

---

## 2. 네비게이션 구조

### 2.1 경영자 앱 - 하단 네비게이션 (5개 탭)

```
┌─────────────────────────────────────┐
│                                     │
│         화면 영역                    │
│                                     │
└─────────────────────────────────────┘
┌─────┬─────┬─────┬─────┬─────────┐
│ 홈  │ 검색 │ 공고 │메시지│ MY   │
│ 🏠  │ 🔍  │ 📋  │ 💬  │ 👤    │
└─────┴─────┴─────┴─────┴──────────┘
```

#### 탭 구성
1. **홈** (🏠) - `/client`
   - 대시보드, 추천 비서, 최근 활동

2. **검색** (🔍) - `/client/search`
   - 비서 검색 (고급 필터)

3. **공고** (📋) - `/client/jobs`
   - 내 구인 공고 관리

4. **메시지** (💬) - `/client/messages`
   - 비서와의 채팅

5. **MY** (👤) - `/client/my`
   - 프로필, 인증 관리, 설정

---

### 2.2 비서 앱 - 하단 네비게이션 (5개 탭)

```
┌─────────────────────────────────────┐
│                                     │
│         화면 영역                    │
│                                     │
└─────────────────────────────────────┘
┌─────┬─────┬─────┬─────┬─────────┐
│ 홈  │ 탐색 │ 활동 │메시지│ MY   │
│ 🏠  │ 🔍  │ 📊  │ 💬  │ 👤    │
└─────┴─────┴─────┴─────┴──────────┘
```

#### 탭 구성
1. **홈** (🏠) - `/secretary`
   - 대시보드, 추천 공고, 프로필 완성도

2. **탐색** (🔍) - `/secretary/explore`
   - 구인 공고 검색

3. **활동** (📊) - `/secretary/activity`
   - 지원 내역, 진행 중인 계약

4. **메시지** (💬) - `/secretary/messages`
   - 경영자와의 채팅

5. **MY** (👤) - `/secretary/my`
   - 프로필, 사진, 배지, 설정

## 3. 화면별 상세 설계

### 3.1 공통 화면 (인증)

#### A-001: 온보딩 & 스플래시
- **경로**: `/`
- **구성요소**:
  - 브랜드 로고
  - 서비스 소개 (스와이프 가능한 3개 슬라이드)
  - "경영자로 시작" / "비서로 시작" 버튼

#### A-002: 로그인
- **경로**: `/login`
- **구성요소**:
  - 이메일/비밀번호 입력
  - 로그인 버튼 (전체 너비)
  - 소셜 로그인 (카카오, 네이버, 구글)
  - "비밀번호 찾기" / "회원가입" 링크

#### A-003: 회원가입 (경영자)
- **경로**: `/signup/client`
- **구성요소**:
  - 진행 단계 표시 (Step 1/3)
  - 이름, 이메일, 비밀번호, 휴대폰
  - 약관 동의 체크박스
  - "다음" 버튼

#### A-004: 회원가입 (비서)
- **경로**: `/signup/secretary`
- **구성요소**:
  - 진행 단계 표시 (Step 1/3)
  - 이름, 생년월일, 성별
  - 이메일, 비밀번호, 휴대폰
  - 약관 동의
  - "다음" 버튼

### 3.2 경영자 앱 화면

#### C-001: 홈 (탭 1)
- **경로**: `/client`
- **상단 영역**:
  - 사용자 인사 "OOO님, 안녕하세요!"
  - 알림 아이콘 (우측 상단)
  - 인증 상태 배지 표시

- **빠른 액션 카드**:
  - 비서 검색하기 (카드형 버튼)
  - 구인 공고 등록하기
  - 인증 완료하기 (미완료시)

- **추천 비서** (가로 스크롤):
  - 프로필 카드 (사진, 이름, 별점, 카테고리)
  - 카드 클릭 → 비서 상세

- **최근 활동**:
  - 최근 본 비서
  - 진행 중인 공고

#### C-002: 검색 (탭 2)
- **경로**: `/client/search`
- **상단**:
  - 검색바 (키워드 입력)
  - 필터 아이콘 (모달 오픈)

- **필터 모달**:
  - 비서 유형 (개인/업무/출장/요가)
  - 나이 범위 (슬라이더)
  - 성별
  - 지역
  - 역량 배지 (영어, 운전, MBA 등)
  - "적용" / "초기화" 버튼

- **검색 결과**:
  - 비서 카드 리스트 (세로 스크롤)
  - 각 카드: 사진, 이름, 나이, 지역, 별점, 배지, "프로필 보기" 버튼

#### C-003: 비서 상세 (미리보기)
- **경로**: `/client/search/:id/preview`
- **구성요소**:
  - 프로필 사진 (블러 처리)
  - 기본 정보 (나이, 성별, 지역)
  - 카테고리 배지
  - 역량 배지
  - 별점/리뷰 수
  - **"5,000원에 전체 프로필 보기" 버튼** (하단 고정)

#### C-004: 프로필 결제
- **경로**: `/client/search/:id/payment`
- **구성요소**:
  - 비서 기본 정보 요약
  - 결제 금액 표시 (5,000원)
  - 결제 수단 선택 (카드, 간편결제)
  - "결제하기" 버튼

#### C-005: 비서 상세 (전체)
- **경로**: `/client/search/:id`
- **구성요소**:
  - 프로필 사진 (최대 5장, 스와이프)
  - 상세 정보 (경력, 학력, 자기소개)
  - 보유 역량
  - 리뷰 목록
  - 하단 고정 버튼: "채팅하기" / "제안하기"

#### C-006: 공고 목록 (탭 3)
- **경로**: `/client/jobs`
- **상단**:
  - "+ 공고 등록" 버튼 (우측 상단)

- **탭 선택**:
  - 전체 / 모집중 / 진행중 / 마감

- **공고 카드 리스트**:
  - 제목, 지역, 금액, 지원자 수
  - 상태 배지
  - 카드 클릭 → 상세

#### C-007: 공고 등록
- **경로**: `/client/jobs/create`
- **구성요소**:
  - 제목 입력
  - 내용 입력 (textarea)
  - 선호 비서 유형 (다중 선택)
  - 지역 선택
  - 근무 기간 (시작일, 종료일)
  - "일정 유동적" 토글
  - 제안 금액
  - "등록하기" 버튼 (하단 고정)

#### C-008: 공고 상세
- **경로**: `/client/jobs/:id`
- **구성요소**:
  - 공고 정보 전체
  - 지원자 목록
  - 각 지원자 카드: 프로필 사진, 이름, 별점, "프로필 보기" 버튼
  - 하단: "수정" / "마감" 버튼

#### C-009: 메시지 목록 (탭 4)
- **경로**: `/client/messages`
- **구성요소**:
  - 채팅방 리스트
  - 각 항목: 상대방 사진, 이름, 마지막 메시지, 시간, 읽지 않은 수

#### C-010: 채팅방
- **경로**: `/client/messages/:id`
- **구성요소**:
  - 상단: 상대방 프로필 (클릭 → 프로필 상세)
  - 메시지 영역 (타임라인)
  - 하단: 메시지 입력창, 전송 버튼

#### C-011: MY (탭 5)
- **경로**: `/client/my`
- **구성요소**:
  - 프로필 카드
    - 사진, 이름, 이메일
    - 보유 배지 (본인인증, 사업자, 매출, 연봉)

- **메뉴 리스트**:
  - 📝 내 프로필 수정
  - 🎖️ 인증 관리 (배지 표시)
  - 📋 계약 관리
  - 💳 결제 내역
  - ⚙️ 설정
  - 🚪 로그아웃

#### C-012: 인증 관리
- **경로**: `/client/my/verifications`
- **구성요소**:
  - 인증 카드 리스트
    1. 본인인증 (NICE)
    2. 사업자 인증
    3. 매출 인증
    4. 연봉 인증
  - 각 카드: 상태 배지, "인증하기" 버튼

#### C-013: 사업자 인증
- **경로**: `/client/my/verifications/business`
- **구성요소**:
  - 인증 방법 선택
    - "API 간편인증" 버튼
    - "서류 제출" 버튼

#### C-014: 사업자 서류 제출
- **경로**: `/client/my/verifications/business/document`
- **구성요소**:
  - 사업자등록번호 입력
  - 회사명 입력
  - 파일 업로드 (사진 촬영 또는 갤러리)
  - "제출" 버튼

### 3.3 비서 앱 화면

#### S-001: 홈 (탭 1)
- **경로**: `/secretary`
- **상단**:
  - 사용자 인사
  - 알림 아이콘
  - 프로필 완성도 바 (85%)
  - 별점 표시 (4.8 ★)

- **빠른 액션**:
  - 프로필 완성하기
  - 공고 탐색하기

- **추천 공고** (카드 리스트):
  - 공고 제목, 경영자 배지, 지역, 금액
  - "자세히 보기" 버튼

- **내 통계**:
  - 프로필 조회수
  - 받은 제안
  - 진행 중인 계약

#### S-002: 탐색 (탭 2)
- **경로**: `/secretary/explore`
- **상단**:
  - 검색바
  - 필터 아이콘

- **필터 모달**:
  - 지역
  - 비서 유형
  - 금액 범위
  - 경영자 인증 배지 (본인, 사업자, 매출, 연봉)

- **공고 리스트**:
  - 카드형 레이아웃
  - 제목, 경영자명, 경영자 배지, 지역, 금액
  - "지원하기" 버튼

#### S-003: 공고 상세
- **경로**: `/secretary/explore/:id`
- **구성요소**:
  - 공고 정보 전체
  - 경영자 정보 (이름, 배지)
  - 근무 조건, 기간, 금액
  - 하단 고정: "지원하기" / "관심 공고 등록" 버튼

#### S-004: 지원하기
- **경로**: `/secretary/explore/:id/apply`
- **구성요소**:
  - 공고 요약
  - 자기소개서 입력 (선택)
  - 희망 금액 입력 (선택)
  - "지원 완료" 버튼

#### S-005: 활동 (탭 3)
- **경로**: `/secretary/activity`
- **탭 선택**:
  - 지원 내역 / 진행 중 / 완료

- **지원 내역**:
  - 공고 카드, 지원일, 상태 (검토중/수락/거절)

- **진행 중**:
  - 계약 정보, 경영자 정보

#### S-006: 메시지 (탭 4)
- **경로**: `/secretary/messages`
- 경영자 앱과 동일한 구조

#### S-007: MY (탭 5)
- **경로**: `/secretary/my`
- **구성요소**:
  - 프로필 카드
    - 사진, 이름, 카테고리 배지, 별점

- **메뉴 리스트**:
  - 📝 프로필 수정
  - 📸 프로필 사진 관리 (최대 5장)
  - 🎖️ 배지 관리
  - 📊 활동 통계
  - 💳 정산 관리
  - ⚙️ 설정
  - 🚪 로그아웃

#### S-008: 프로필 수정
- **경로**: `/secretary/my/profile/edit`
- **구성요소**:
  - 기본 정보 (이름, 생년월일, 성별, 지역)
  - 카테고리 선택 (다중)
  - 경력 입력
  - 학력 입력
  - 자기소개
  - "저장" 버튼

#### S-009: 프로필 사진 관리
- **경로**: `/secretary/my/photos`
- **구성요소**:
  - 사진 그리드 (최대 5장)
  - 각 사진: 드래그로 순서 변경, 삭제 버튼
  - "+ 사진 추가" 버튼 (촬영 또는 갤러리)

#### S-010: 배지 관리
- **경로**: `/secretary/my/badges`
- **구성요소**:
  - 보유 배지 리스트
  - 획득 가능한 배지 리스트
  - 각 배지: 아이콘, 이름, 설명
  - "배지 추가" 버튼
